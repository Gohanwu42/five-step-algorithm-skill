## Existing process and explicit automation: regional report

**Input:** Replace manual CSV retyping with a local Python script accepting input and output paths. Keep reconciliation, originally added after an error. Report only totals by region; accept negative returns, expose invalid amounts, and do not schedule or email. Historical timing and the reconciliation owner are unknown.

Fixture:

```csv
order_id,region,amount
A1,North,10.25
A2,South,7.50
A3,North,2.75
A4,South,-1.00
```

**Observed:** The assistant created the sample, script, regional output, and local tests. It retained reconciliation against the serialized report, reported invalid input as an error, and protected the source and prior report from failed writes.

**Checked:** The script, test code, output, and test log were inspected. Eight local tests passed, covering the sample and return, invalid input with and without an existing report, decimal precision, malformed records, source-overwrite prevention, corrupted-output reconciliation, and failed output replacement. A separate artifact check confirmed North `13.00`, South `6.50`, and grand total `19.50`.

**Result:** Pass for the tested behavior. This was a local fixture run; production data, scheduling, deployment, and time savings were not validated.
